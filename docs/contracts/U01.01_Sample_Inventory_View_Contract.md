# U01.01 — Shared sample inventory preview

Status: in review. REQ-010/012. This is a read-only M01 slice, not completion of
Data Mapper or publication of a confirmed dataset to ALA.

## Source and ownership

The existing `/data-mapper` route mounts `SampleInventoryPreview`. It calls
`useDemoSession()` once, using the global U00.05 provider and its SSR-safe snapshot.
No second controller, fixture load or deal state is created. Before ready/session
availability, a neutral `status` says the shared inventory is being prepared;
there are no placeholder rows or fabricated counts. The bundled example normally
has 15 Buyer and 15 Target applications, but displayed counts are always derived.

Names, dataset version, currency and applications come from `session.current_deal`.
The screen displays “Synthetic example data,” the dataset version and a read-only
notice. Later controller changes render through the existing subscription, including
global reset; the component never writes to the controller or storage. The older
U00.02 loader example remains a data-source reference; the current UI composes that
data through the subsequently implemented U00.05 session, as required by this packet.

## Exact field map

| Source field | Header | Presentation |
| --- | --- | --- |
| `app_id` | Application ID | Opaque, unchanged row header and React key |
| `app_name` | Application name | Current source text |
| `function` | Business function | Current source text; no inference |
| `vendor` | Vendor | Current text or Not provided |
| `annual_cost` | Annual cost | `Intl.NumberFormat('en-CA')`, session currency code, yearly amount |
| `criticality` | Criticality | Low / Medium / High / Critical, or Not provided |
| `deployment` | Deployment | Cloud / On-premise / Hybrid, or Not provided |
| `lifecycle` | Lifecycle | Active / Legacy / Retiring, or Not provided |
| `owner` | Owner | Current text or Not provided |
| `notes` | Notes | Escaped, wrapping source text or Not provided |

`company_side` selects the Buyer or Target inventory; it is not inferred from
the company/application name or ID. Filtering preserves source order and stable
identity. No sorting, pagination, search or mutation exists. Zero cost renders
explicitly as `CAD 0.00` for CAD (locale spacing may be nonbreaking); null renders
`Not provided`. Missing enum/text values also render `Not provided`. No null is
coerced into zero, and no financial calculation or recommendation is performed.

## Tabs, responsive table and session behavior

New mounts default to Buyer. Native tab buttons use one `tablist`, two linked
`tab`/`tabpanel` pairs, `aria-selected`, one tab stop, and unique React `useId` IDs.
Left/Right toggles and wraps; Home selects Buyer; End selects Target. Selection
and focus move together on these keys. Clicking changes selection, and native
Enter/Space work. Visible “Selected” text and semantic selection convey state
beyond color. Tab switching changes local view state only, without URL/storage,
source revisions, metadata or dataset version changes.

Only the selected panel renders its table; the other panel remains hidden. An
empty selected side renders a truthful empty message, with no invented row.
The current strict fixture schema requires both sides; the defensive empty branch
does not weaken that schema or publish a new dataset convention.

The table has a caption, column scopes and stable-ID row headers. Its named,
focusable scroll region and linked hint support keyboard horizontal scrolling.
The table stays compact with wrapping cells inside that region at narrow widths;
the page itself must not overflow. Existing A1 tokens and focus rings are reused.

Existing session edits survive same-tab navigation/refresh through the unchanged
provider. Global Reset restores fixture values and metadata exactly as U00.05
defines. Side selection is ephemeral and returns to Buyer on remount; global
reset need not change the selected side. Denied storage behavior remains owned by
the global provider and its existing notice.

## Exclusions and verification

CSV selection/parser (U01.02), column mapping and Confirm (U01.03), publication/
version mutation (U01.04), editors, AI analysis, recommendations, exports, backend
routes and additional storage remain unimplemented. No Load sample action is
needed because the shared session already initializes the example. Other eight
module intros retain their current messaging and disabled AI notices. Only the
obsolete all-introductions Home sentence changes. The seven future icons stay inert.

`npm run check:data-mapper` checks source order/IDs, all fields, dynamic counts,
null/zero/currency/enums, read-only projections and existing controller updates,
restore/reset. It is registered once in `check:ci`. Optional `--browser` uses only
an existing Chromium executable via Node/CDP, configured by `AIVRA_CHROMIUM_PATH`;
no AISFA/Playwright installation is required. Browser checks compare every actual
table cell, keyboard semantics, mobile containment, persistence/reset and routes.

No manual screen-reader/full WCAG certification is implied by these checks.
Rollback is reverting this bounded preview/test/doc diff, with no migrations or
external resources. The next unit is U01.02, separately authorized.
