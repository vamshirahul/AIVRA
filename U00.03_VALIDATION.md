## Implementation

One public layout supplies header, grouped navigation, main landmark, footer,
visible keyboard focus and skip link. A single navigation tree serves desktop
and mobile. Mobile navigation is an in-flow disclosure, not an overlay: the
content moves below it, so there is no backdrop, trapped focus or covered page.
Escape at the toggle or inside navigation closes it and restores focus. Choosing
a route closes it. `aria-expanded`, `aria-controls` and `aria-current` describe
the state; hidden mobile links are not keyboard reachable until opened.

The [README route map](README.md#responsive-workspace-u0003) contains Home plus
exactly nine distinct module routes across six approved groups. A shared static
module route supplies unique headings, purpose, honest incomplete state and real
links. Unknown module paths return 404. Home reads the existing fixture loader
for Northstar/Meridian and the actual **15 / 15 / 10 / 5** counts, labelled as
source records with no analysis run. Navigation is independent; no workflow is
forced. The exact required disclosure is present sitewide.

Tailwind CSS/PostCSS uses semantic CSS variables. Small native Card, Badge,
button-link and navigation primitives provide the restrained shadcn/ui-style
composition without a component toolkit dependency. Typography uses local system
fonts; no remote font, image, icon, chart or animation service is loaded.

available outside this repository. No browser/test framework was added to the
manifest. To reproduce with an available local installation, start the app, then:

```powershell
$env:AIVRA_PLAYWRIGHT_PATH='C:\Users\vamsh\source\AISFA-App_V1\node_modules\playwright-core'
```

Set these variables to your own existing tool installation on another machine.
Optional `AIVRA_BASE_URL` and `AIVRA_EVIDENCE_DIR` override the local URL and
artifact directory. The app itself needs neither test tool nor these variables.
