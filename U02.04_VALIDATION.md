## Validation choices, limits and gates

Original action is always derived from trusted projection; the overlay stores only
the immutable reference, visitor proposal/reason/origin and result identity. No
copied AI answer becomes official output. Reason-only identical original action is
a no-op/removes its overlay; commentary is not stored as a false change. Identical
override including reason is a no-op; changed reason on a changed action updates
visitor commentary. All proposed destinations are explicit, never selected locally.
Restore can be rejected if it would duplicate/conflict with a peer override; peers
must be explicitly edited/restored, never silently rewritten.

Drafts are mounted UI memory only and disappear on refresh/navigation/invalidation.
No browser/server persistence, metadata writes, exports or downstream consumers.
Projection exposes no session token, so reset/freshness continue through the existing
trusted projection owner (outdated/invalid/absent), not a newly invented client digest.
Pure effective enumeration retains visitor origin and is not a published contract.

Test specimens are fabricated structured inputs, not actual model executions or
new model approvals. Fetch blocked in focused tests/SSR; **zero provider/network
attempts or API charges**. Original LLM-only recommendation boundary remains.
No implementation blocker or unauthorized change. Future protected result delivery,
ADR-012 provider/model/pricing/terms/quality, durable atomic usage controls, trusted
anonymous ingress, independent approved caps/provider protections, bounded live-test
