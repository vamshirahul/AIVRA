## Export dictionary and fidelity

`lib/playbook-generator/review-export.ts` constructs the strict, typed,
construction-only **playbook/review-export/v1** dictionary below. The original
outcome is already strictly validated and source-authorized by U04.02/U04.03;
the saved overlay is revalidated by `projectPlaybookReview`. No duplicate browser
model schema, arbitrary object spreading into the root, permissive parser,
normalization, imported result or structural-validation-to-trust API is added.

| Field | Exact meaning |
| --- | --- |
| contract_version | literal playbook/review-export/v1 |
| artifact_kind | literal reviewed_playbook |
| illustrative_unapproved | literal true |
| disclosures | Three fixed PLAYBOOK_EXPORT_DISCLOSURES: unapproved/no obligations or financial benefit; unassigned roles/unverified dates/unknowns; structural coverage is not narrative quality/decision verification |
| original | Exact complete accepted U04.02 outcome: operation, status, unmodified adapter envelope/data/provenance/usage, coverage and source |
| review | Validated separate playbook/review-draft/v1 overlay: exact binding, visitor_edit changes and reasons; empty overrides means original fields retained, not visitor approval |
| effective.phases | Phases sorted by original sequence. Each holds unchanged original phase, activities and milestones in original within-phase array order |
| effective.phases[].activities/milestones | Existing U04.03 projection entries: id, complete original row, effective editable values, origin and nullable visitor_reason |
| source_identity | Exact selected_scenario, original captured source and original coverage, including missing IDs/not_addressed/incomplete_context |

Original phases/actions/milestones/risks/omissions/limitations, assumptions,
dependency and after-activity IDs, source references and Buyer/Target sides,
ownership uncertainty, proposed dates, adapter provider/model/mode/routing reason,
request/input digest/prompt/generation time and available usage stay intact.
No missing metadata is synthesized; optional fields remain absent; null remains
null. Text/Unicode/CRLF/control characters and all original array order survive
JSON round-trip exactly. Phase ordering changes only the derived readable view,
never original arrays. Original and visitor values are reconstructable without
calling a model, inferring recommendations or calculating money.

Canonical UTF-8 JSON: **aivra-playbook-reviewed-v1.json**,
`application/json;charset=utf-8`. Deterministic compact JSON.stringify; no export
timestamp. No import/reader is offered. Parsing a downloaded JSON cannot mint a
protected source, permit, currentness or editing/export authorization.

## Human-readable Markdown

UTF-8 **aivra-playbook-reviewed-v1.md**, `text/markdown;charset=utf-8`.
Same frozen capture as JSON, with prominent AI-generated/visitor-reviewed/
illustrative/NOT APPROVED disclosure, actual model metadata and source revisions/
digests/scenario, structural coverage/missing context, ordered phases/assumptions/
references, effective activities/roles, dependencies, original fields/evidence/
uncertainty, effective milestones/proposed dates/bases/after-activity links,
original risks/limitations/not-addressed sources and separate saved overrides.
Unknown fields say Unknown / not supplied; no person/date/approval/savings is invented.

Only exporter-owned headings, bullets and emphasis form Markdown syntax. Every
model/visitor value, including strings inside JSON-like readable detail, passes
`playbookMarkdownText`. ASCII Markdown punctuation, raw HTML punctuation, ampersands,
links, backticks, pipe delimiters and fence characters become numeric entities
before Markdown tokenization. C0/C1 controls, DEL, bidi/format and line separators
become visible literal backslash-u sequences (backslash is also an entity), so
embedded CRLF cannot create new headings or break fences. Source entity text is
escaped once and cannot inject an active tag. No raw untrusted HTML, image, remote
resource or link is generated. Common Markdown processors decode numeric entities
as literal inline text; do not decode and reparse it as Markdown/HTML a second time.
JSON is authoritative for exact whitespace/control semantics. No renderer library
or claim about every third-party Markdown processor is introduced.

## Source authority and capture lifecycle

The sole model authority remains `createPlaybookReviewSource` and the actual
U04.02 owner's issued-object/currentness check. A schema, boolean, digest or
imported/cloned result is not authority. Existing protected in-memory composition
must provide honest authoritative readers/notifications; arbitrary trusted script
injection/fabricated functions are outside this API boundary, not authenticated
by opaque TypeScript brands. No public delivery/ingestion endpoint is introduced.

`capturePlaybookExport(read)` is called only after an explicit Download click.
It obtains the mounted owner's latest source, saved draft, actual browser session,
editing flag and monotonically increasing review-action revision. It requires a
current source view, exact valid saved review and matching session/fixture/input
revisions. It copies/freezes one complete artifact and records source/view identity,
draft object identity and contents, full session bytes and action revision in a
private WeakMap keyed by an opaque frozen permit. The source subscription revokes
on any notification. An async WebCrypto full-deal digest is an additional integrity
check; exact live state and permit are rechecked after the await. It cannot grant
source authority. Capture failure produces no download or partially authorized file.

`preparePlaybookDownload(permit,format)` synchronously rechecks the live protected
source on every click, exact captured view, saved draft object/content, full current
session/source key, revision, editing=false and permit presence. It serializes only
the frozen capture. Both format clicks reuse it while current. No generation,
calculation, source refresh or silent overlay replacement occurs during serialization.
Mismatch permanently revokes that permit even if values later revert.

The workspace revokes synchronously before opening a form, Save (including failure),
Cancel, Restore row/all, and in layout-effect unmount cleanup. Opening even an
unchanged form disables both buttons, covering every later keystroke without stale
React closures. Immediate refs protect async capture and rapid same-task edit races.
Source/session/Reset/review/scenario/replacement changes invalidate/hide the existing
editor. In-flight captures re-read mounted state and cannot survive navigation.
Only another explicit Download can capture the new saved review. Refresh/navigation
still discards the temporary U04.03 overlay; no session/storage schema changes.

## Limits, download port and feedback

Captured compact artifact and each complete serialized format independently have
a **1,500,000 UTF-8 byte** cap measured by TextEncoder. Existing 64,000-byte model
envelope/review-overlay and 128,000-byte request limits remain unchanged. Escaping
can expand Markdown independently. Refuse wholly, never truncate/split/drop fields.
Current genuine Playbook limits are normally much smaller than this defense cap.

Fixed safe codes/messages: export_unavailable (absent/unauthorized/stale/dirty/
invalid), export_too_large, download_unavailable. No raw payload/exception/secret
is displayed. Preparation completes before Blob/object URL creation. Existing
ALA DownloadPort is reused as a type; anchor/URL pattern matches CSE/scenario.
Currentness is checked again after URL allocation and immediately before click.
Anchor removal runs in finally, failure URLs revoke immediately, success revokes
on the next task. Cleanup-scheduling failure also revokes immediately. Browser
resource revocation is best effort if the browser itself throws on revoke.
Product acknowledgment says **Download initiated**, not disk-save success.

One A1 export area has native labeled secondary Markdown/JSON buttons, polite
availability/progress/failure feedback, explicit unknown/incomplete/unapproved
disclosures, inherited focus styles and responsive wrapping. Save/Cancel/Restore
focus behavior remains unchanged. No download runs on mount/render/refresh/state
change. No-source/stale UI has no populated controls or pretend export affordance.
