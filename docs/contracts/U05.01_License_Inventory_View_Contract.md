# U05.01 — Read-only current-session license inventory

Status: **in review**. Exact G2 outcome: Display small synthetic license inventory
linked to app IDs; U00.02/U00.05; REQ-070. Acceptance: license fixtures linked to app
IDs, quantities/spend visibly synthetic. No U05.02–04 behavior is implemented.

## Ownership, identity and current source

`LicenseInventory` consumes one `useDemoSession()` snapshot and reads only
current_deal.license_positions/applications/currency, fixture.dataset_version and
input_revisions.licenses/applications. It has no local store/effects or fixture loader.
The existing shared controller owns updates, persistence/hydration and Reset; no
schema/key/version/data changes or viewer-triggered writes/metadata registration.

`licenseInventoryRows` preserves every license position in source order. Row identity
is exact license_id, lookup identity exact app_id. Application name and Buyer/Target
come from the current matched application, never vendor/product/ID prefix or index.
Renaming/reordering source does not change identities. Duplicate application IDs are
ambiguous and displayed unresolved; missing links show exact app_id with `Unresolved
application reference`, never guessed/repaired. Existing strict session validation
still rejects dangling links. Null ready session shows unavailable; not-ready shows
neutral loading. A valid zero-license session has a truthful empty state.

Bundled data has ten licenses, but count is derived, not a validation rule: current
valid sessions may contain zero through the existing 200-position bound. Multiple
licenses on the same application remain separate positions; no deduplication/totals.

## Field dictionary and display semantics

| Column | Original source and behavior |
| --- | --- |
| License ID | license_id unchanged; row header/stable React key |
| Application ID / side / name | exact license.app_id + current matched application.company_side/app_name |
| Vendor | license.vendor, independent of application vendor; null is Unknown |
| Product | license.product unchanged |
| Entitled quantity | seats_entitled; 0 is 0, null Unknown |
| Estimated usage | seats_used; 0 is 0, null Unknown; source observation, not verified utilization |
| Annual license spend | annual_spend, deal currency; null Unknown, 0 currency zero; no FX or app-cost addition |
| Renewal date (YYYY-MM-DD) | exact source ISO date, no timezone conversion/current-date classification; null/absence Unknown |
| Notes | complete notes as escaped text; null Unknown, wrapping preserves whitespace |

Money formatting uses en-CA/currency code, up to twenty fractional digits. Positive
amounts below 1e-20 use exact JavaScript numeric scientific text with the currency
code, so known nonzero does not become displayed zero. Source number precision is
not extended or inferred. Annual license spend is not application annual cost, a
savings calculation, a total spend claim or legal/contract interpretation.

Summary includes license-position count, deal currency, fixture dataset version and
both source revisions. Synthetic/fictional amounts and quantities are explicitly not
contract evidence or verified entitlements. `No AI license analysis has run` is
visible, with future opportunity analysis identified as unavailable. The route keeps
exactly one existing AIStatusNotice/not_enabled; no paid/fallback identity or results.
