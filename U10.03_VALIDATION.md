## Integration, states and limits

The public route passes no source: Ask is disabled, question preparation and Reset
work locally, and no chat requests or fake answers are created. The additive
server presenter retains real opaque U10.02 handles/caller identity privately,
revalidates owner successes and projects only bounded display fields.
It is not a serialized transport or a public authorization grant. A future
separately approved protected delivery architecture remains necessary.

Implemented states: initial, ready, invalid question, submitting, answered,
insufficient evidence, AI disabled, safe provider/budget/fallback/rate/concurrency
errors, source stale, history limit and Reset completed. User questions retain
order. Over-limit text/history is rejected rather than silently truncated.
Reset clears only composer/transcript/private conversation, requires a fresh
conversation for subsequent Ask and returns focus to the composer.

Latest actual session and subscribed authoritative source changes invalidate
answers, including saved review/assumption/Playbook changes. Pending Reset,
source updates and unmount cannot revive stale results. Original findings,
visitor decisions, unknown values and source identities remain distinct.

No changes to underlying U10.01/U10.02 contracts, router/adapter, provider factory,
budget/fallback/pricing/model policy, owner history rules, business calculations,
session schemas, dependencies or live activation. No prompts, source bodies,
caller keys or internal request/session/conversation IDs cross into display views.
The seven Future Features remain inert.
