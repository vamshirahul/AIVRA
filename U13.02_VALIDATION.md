## D. Source authority/currentness/security

HealthPresentationSource is an in-memory function-bearing composition interface,
not a server handle serialization, browser current=true flag, public API, singleton
or production delivery bridge. Genuine future sources must use U13.01 ownership/
currentness and actual full-session matching. No source is installed publicly.

The strict supplemental browser display schema bounds exact fields/states/counts/
money units/warnings/source metadata. It does not prove AI execution or financial
truth. Current populated views additionally require source.isCurrent on the exact
object, matchesSession, exact session/fixture/revisions and matching current
application/TSA counts. Cloned JSON or invalid extra fields do not gain authority.

A mounted notification revision triggers revalidation even if an owner revokes the
same snapshot object. Shared-session provider changes synchronously hide mismatched
protected values; Reset cannot leave old values current. There is no polling,
background inference, persistence or Refresh control. Broad U13.03 mutation/UAT is
deferred; the component's own stale/Reset display safety is verified here.

React escapes text; no generated HTML, unsafe Markdown, fabricated links, analytics,
prompt logging, credentials or transaction mutations. No server runtime is imported
into browser code. Existing AI/router/budget/fallback hard stops and seven inert
Future Features remain unchanged.
