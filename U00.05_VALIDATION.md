## Implementation and decisions

One root provider owns a controller and shared React snapshot, persisted to
`aivra:r0:demo-session:v1`. Independent session schema version: `1.0.0`.
The current deal reuses the existing full fixture contract. Separate app/license/
TSA counters support typed record updates and an empty source-freshness registry.
Invalid updates are rejected atomically; no-ops do not increment revisions.
Captured snapshots include a session-lifetime UUID so results captured before a
reset cannot be registered as fresh afterward. Stale metadata is retained, not
silently deleted, recomputed or treated as an AI/business result.

Home names/counts use shared current data after safe hydration. A small status
strip offers inline keyboard confirmation/cancel for reset, recovery notice and
memory-only storage notice. A1 tokens/navigation and seven inert future icons
are preserved. No editor, importer, AI call, business rule, auth or database.

API, bounds, dependency map and failure behavior:
[U00.05 session contract](docs/contracts/U00.05_Browser_Session_Contract.md).
