## E. Failures, conversation and security

The new suite reuses the existing U10.03 test fixture with additional **script-only**
hooks: latest source replacement/subscription, captured requests, output/provider
faults, policy/store injection and monotonic fake-clock advancement. No runtime
owner/router/policy/session code changes. No new fake business dataset.

A successful original answer is retained before exercising provider, timeout,
reservation/store and settlement exceptions. Safe error vocabulary preserves the
prepared question/history; private exceptions are suppressed. Failed providers do
not trigger a second dispatch or fallback. Paid/fallback allocation remains
independent; rate/concurrency gates use the existing fake store.

Actual Unicode history reaches the existing byte ceiling before its next append;
previous turns remain byte-identical. Reset clears chat only; pending completion
cannot return a transcript. Existing chat tests cover navigation/unmount suppression
and private view rejection; existing Ask tests cover strict full envelope provenance,
complete payload limits and no provider bypass.

Malicious question/source/answer text remains literal untrusted data, never a
system instruction or tool/action. Schema-valid malicious prose can still be
semantically wrong: these tests establish no mutation/execution or instruction
promotion, not universal prompt-injection immunity or narrative truth.
No HTML renderer, public endpoint, auth requirement, storage, credentials,
analytics/body logging or cross-owner handle transfer is introduced.
All seven Future Features remain inert.
