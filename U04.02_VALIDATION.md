playbook with playbook/v1 prompt and exact server-owned instructions. Preserve the
existing full-deal validation and exact app-then-TSA allowlist. No user_text growth,
serialized/truncated escape hatch, arbitrary JSON, output-contract or model input.

Moving only the existing static input schema to input-schema.ts prevents the cycle
AI contracts -> Playbook builder -> ALA presentation/analyzer -> router -> adapter.
Original public exports stay at input.ts, with identical shapes/versions. Generic
source consistency is not authentication of imported analysis; the builder obtains
the original protected outcome and reconstructs reviewed/scenario context itself.

UUIDs. Fresh authoritative reads bracket the sole orchestrator await. Accepted
outcomes retain unchanged envelope metadata and exact U04.01 source identity;
no source/session registry is written. A private weak ownership map permits only
this owner's issued object for regeneration/currentness, not parsed/cloned files.

after changed sources. No automatic regeneration or provider-error failover/retry.
