# U04.03 — Temporary Playbook activity/milestone review

2026-11-04 UTC; in review, offline populated functionality only.

Exact local G2 objective: **Display editable AI draft activities and milestones**.
Dependencies: **U04.02 U00.05**. Requirement: **REQ-042**. Exact register acceptance:
**Edit stays in session; original AI metadata preserved; stale source notice shown**.
G2 and register agree. G0's modify/regenerate requirement is split: U04.02 owns
regeneration, this unit owns editing, U04.04 owns reviewed Markdown/JSON exports.

## Authorized fields and boundaries

| Entity | Editable | Preserved read-only |
| --- | --- | --- |
| Existing activity | title<=120, description<=800, nullable proposed ownership_role<=120 | activity_id, phase_id, source_refs, dependency IDs/graph, assumptions, uncertainty |
| Existing milestone | title<=120, nullable ISO proposed_date and nullable date_assumption<=400 | milestone_id, phase_id, source_refs, after_activity_ids |
| All other content | None | phases, risks, coverage/not_addressed, original evidence/uncertainty, provenance/usage, source/review/scenario identity, original ALA/CSE/Scenario/TSA data |

G2 authorizes editing activities/milestones but does not explicitly authorize
dependency/assumption/link editing. The packet requires explicit authorization
for those extra fields, so they remain read-only. No new phase/activity/milestone/
risk/approval/assignee/status record is created. No local business recommendations,
financial calculation or regenerated text is introduced.

Role is a proposed functional role, not an assigned person. Null stays unassigned/
unknown; only an explicit visitor edit changes it. UI blank role means an explicit
clear to null; whitespace-only text is invalid, not silently trimmed. Proposed
dates are exact calendar ISO dates, not timestamp/timezone conversions. Nonnull
date requires nonblank basis, and unknown date requires null basis. Both original
and visitor dates remain unverified proposals, not contractual commitments.

## Protected source ownership

The new server-only `createPlaybookReviewSource(owner,outcome,readSource,subscribe)`
calls unchanged U04.02 owner.isCurrent. The exact outcome must be an object issued
by that owner; a parsed/cloned export or type-valid envelope cannot grant a review.
It validates the existing PlaybookOutcomeSchema without normalization and copies a
deeply frozen view with full original outcome plus the original scenario selection.
Checks bracket source capture. No new model metadata or trust token is minted.

The source exposes a stable getSnapshot and subscription to its trusted source owner.
The owner must notify every source/review/scenario/result change. getSnapshot also
checks currentness on every access, even if notification is delayed. Once revoked,
the source stays outdated; a new current result requires a new authorized source.
No public endpoint or result-delivery/import operation is introduced.

Client code accepts a PlaybookReviewSource interface, not current=true or a JSON
envelope/hash. Its opaque type is granted only by protected composition. These
in-memory functions/types are not serialized authentication or a defense against
arbitrary trusted JavaScript injection. A future production delivery design must
provide authoritative ownership/currentness; this unit does not manufacture one.
The public component supplies no source, so no populated UI can appear there.

The workspace additionally checks current browser-tab session/fixture/all input
revisions/session revision and SHA-256 of the full current deal. Digest matching is
local integrity only, not a source-authority grant. The raw current-deal/session key
hides/unmounts a previous editor synchronously before async digest checks finish.
An effect ticket discards superseded checks; source currentness is rechecked after
the digest await. Save/Restore also re-read current authority and the actual session
controller snapshot, protecting stale render handlers.

Reset, source edits, changed review/scenario/assumptions, unversioned source content,
revocation and replacement result identity invalidate the old review/editor. Stale
originals are not shown as current: controls disappear and an explicit stale notice
is displayed. Unsaved and saved visitor overlays are discarded when the editor
unmounts or its binding changes. No stale comparison/history feature is added.

## playbook/review-draft/v1

Strict browser-safe PlaybookReviewDraftSchema:

| Field | Meaning |
| --- | --- |
| contract_version | playbook/review-draft/v1 |
| status | visitor_draft_unapproved |
| binding | Exact generated request UUID, input_digest, playbook/v1 prompt and captured U04.02 source object |
| binding.source | Session UUID/fixture versions, session revision, application/license/TSA revisions and deal/review/scenario SHA-256 digests |
| overrides | <=140 unique existing activity/milestone rows, each kind/id, strict partial changes, visitor_reason and origin=visitor_edit |

Each material override requires a nonblank reason<=400 characters. Only supported
changed fields are retained, not complete cloned model rows. Unknown keys,
undefined values, empty changes, redundant unchanged fields, duplicate IDs, foreign
IDs, wrong binding, forbidden graph/reference/phase/uncertainty fields and invalid
dates/bases fail. Complete serialized overlay is capped at 64,000 UTF-8 bytes;
oversize fails atomically and retains the previous saved review. No existing model
or source bound is raised.

savePlaybookEdit validates current source, the saved draft and the complete proposed
editable values. It computes a minimal patch relative to true original AI fields.
No-op changes create no overlay; saving original values removes the override.
Reason-only changes on an existing material override remain explicit visitor edits.
restorePlaybookRow removes the one overlay; Restore all creates the empty review
for that same current binding. Failures never mutate the last saved draft or original.
Cancel affects only the unsaved form and restores focus to its Edit button.

projectPlaybookReview returns separate display entries containing original,
effective editable values, visitor reason and origin. It never constructs a new
model result/envelope or labels visitor text as AI-generated. Original outcome,
phases, graph, refs, metadata, risk/uncertainty and incomplete coverage remain intact.
Graph/link integrity is preserved by construction: none of those fields can be
changed in this unit. Existing server schemas verify original integrity before
ownership projection; malformed/cyclic/orphaned forged outcomes cannot obtain a
source. No duplicate browser recommendation/graph engine is introduced.

Draft operations and rendering use escaped text only. Browser code has no runtime
server import or inspectPlaybookResult call. Type-only imports are erased. The
original server-only output schema/provenance/AI guard contracts are unchanged.

## Workspace behavior and accessibility

Activities/milestones are grouped by original phases in responsive A1 cards. The
workspace shows illustrative/unapproved disclosure, scenario selection, actual
original provider/model/mode, timestamp/request/prompt/digest and source revisions.
Incomplete coverage/missing IDs, unknown roles/dates and original risks/omissions/
limitations remain visible. Read-only details preserve all original fields/refs.

Native labeled forms provide bounded fields, per-field aria-invalid/describedby
errors, disabled Save while invalid, a nonblank justification and fixed form-level
failure feedback. Open focuses Title; Save/Cancel return focus to the invoking Edit
button. Save/Restore feedback and edit count are announced in a polite status.
Only one form is open; other row actions are disabled until Save/Cancel. There is
no automatic generation, approval, assignment, risk prediction or source mutation.

Overlays live in React state only for this mounted workspace. This follows the
existing temporary review pattern: leaving the route, refresh, replacement or Reset
discards review state. No shared session schema/key changes, sessionStorage write,
database, new persistence or export. This is not durable or cross-navigation review.

The public Generate component mounts an unavailable review workspace with no source.
Its existing body-free availability POST, repeat-click/abort behavior and unchanged
import-free503/no-store endpoint remain. No fabricated cards, editable public sample,
query/env/storage activation, new result endpoint or Regenerate affordance is added.
