M15, M17 and M18. Exact labels match the packet, with a distinct lightweight
local SVG per item and visible **Planned** text. M06 and M16 are absent.

active `nav`, within the same desktop sidebar/mobile disclosure. Rows are plain
list content, not disabled controls. Visible text supplies each accessible name;

focus targets, tooltips, pointer cursor or hover affordances were added. Names
wrap naturally. Minimal CSS reuses A1 muted text, border and white surface;
computed text/icon contrast is **6.26:1**.
